# Proyecto IoT - Grupo 12 - ESTACIONAMIENTO INTELIGENTE
## 
## Descripción del proyecto
El proyecto de Estacionamiento Inteligente propone una solución avanzada y eficiente para la gestión automatizada de un aparcamiento, utilizando tecnologías de Internet de las Cosas (IoT). Este sistema integra diversas funciones clave para mejorar la seguridad, la eficiencia y la experiencia general de estacionamiento.

### Componentes Principales:

* Item Sensores de Estacionamiento:
Se instalarán sensores en cada espacio de estacionamiento para detectar la disponibilidad. Estos sensores enviarán información en tiempo real sobre la ocupación de los espacios.

* Item Sistema de Ventilación Automatizado:
Sensores de gas y humo estarán distribuidos estratégicamente para monitorear la calidad del aire. En caso de detectar anomalías, se activará automáticamente un sistema de ventilación para garantizar un entorno seguro.

* Item Registro de Matrículas:
Se implementará un sistema de reconocimiento de matrículas mediante cámaras de alta resolución. Las matrículas de los vehículos que ingresen al estacionamiento serán registradas y asociadas a un tiempo específico.

* Item Asociación de Tiempo y Estacionamiento:
La información de registro se almacenará en una base de datos central, permitiendo la asociación precisa entre el tiempo de llegada y salida de cada vehículo. Esto facilitará la gestión del estacionamiento y proporcionará datos útiles para análisis y reportes.

* Item Control de Acceso mediante Matrículas Conocidas:
El sistema permitirá la configuración de matrículas autorizadas. Cuando se detecte una matrícula reconocida, se activará automáticamente la barrera de acceso, permitiendo la entrada o salida del vehículo sin intervención manual.

### Beneficios del Proyecto:

* Item Optimización del Espacio:
La información en tiempo real sobre la ocupación del estacionamiento permite una mejor utilización del espacio, reduciendo el tiempo de búsqueda de lugares disponibles.

* Item Seguridad Mejorada:
El sistema de reconocimiento de matrículas y la gestión automatizada de accesos mejoran la seguridad al prevenir el acceso no autorizado.

* Item Eficiencia Energética:
La activación automática del sistema de ventilación solo cuando sea necesario contribuirá a la eficiencia energética del estacionamiento.

* Item Análisis de Datos:
La recopilación de datos permitirá realizar análisis detallados sobre el uso del estacionamiento, tendencias de ocupación y patrones de entrada y salida.
